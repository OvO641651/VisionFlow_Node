# VisionFlowNode 用户手册

> **这是什么**：一个"像海康 VisionMaster 那样"的节点式机器视觉软件 —— 你在画布上把一个个功能方框连成一条流程（"数据流"），
> 软件按顺序执行它们：**采集**图像（图片 / 视频 / 摄像头）→ **处理**（灰度、滤波、二值化…）→ **检测**（直线、圆）→ **输出**（存图 / 存视频）。
> 每个方框的参数、处理区域（ROI）都可以单独设置，**同一套流程可以套用到图库里的每一张图上**，各图参数互不干扰。
>
> **本手册面向使用者**（不写代码）。想了解代码结构请看《代码说明书》，想了解设计取舍请看《项目技术文档》与《批次4 技术方案》，改动历史看《开发日志》。
>
> 文档版本：v1.0（2026.10.7），对应软件批次4（目标3-M5 完成）。

## 一、五分钟上手：做一个"直线检测并保存结果"

**目标**：读一张图 → 检测直线 → 把"带检测叠加"的结果存成图片。

| 步骤 | 操作 | 你会看到 |
|---|---|---|
| 1 | 点顶部 **「打开文件」**（或图库工具栏 **「＋图片」**）选一张图片 | 图片出现在**右侧显示区**，同时以缩略图出现在**图库列表**里；工具栏左边显示 `图像源 (1/1)` |
| 2 | 在**左侧项目树**里双击 **采集 → 图片源** | 画布上出现一个「图片源」方框（也可以直接把树项**拖到**画布上，方框落在鼠标位置） |
| 3 | 双击树里的 **检测 → 直线**，再双击 **采集 → 输出图像** | 画布上共有三个方框（位置会自动错开；用鼠标拖动可以挪） |
| 4 | **连线**：在「图片源」方框**下边缘的圆点**上按住鼠标左键，拖到「直线」方框**上边缘的圆点**，松手 | 两个方框之间出现一条线。同样把「直线」连到「输出图像」 |
| 5 | 双击 **「输出图像」** 方框打开参数窗口 | 窗口里只有"运行参数"一页 |
| 6 | 在 **「输出目录」** 右边点 **选择目录…**，选一个文件夹（比如 `D:\out`）；「输出文件名」留空即可 | 文件名留空 = 用输入图片的文件名 |
| 7 | 点参数窗口里的 **「确定」** 关掉窗口 | —— |
| 8 | **先用鼠标点一下画布上的「输出图像」方框**（选中它），再点顶部 **「连续执行」** | 右侧显示图上出现**绿线**（检测到的直线）；底部**执行日志**出现 3 行：图片源 / 直线（检测到 N 条直线）/ 输出图像（已保存 …） |
| 9 | 打开 `D:\out` 文件夹 | 里面有一张 `图片名_0001.png`，图上带着**绿线** |

**为什么第 8 步要先选中「输出图像」？** 因为**「连续执行」只执行到"当前选中的那个节点"为止**（见第五节）。
想让它执行整条链，就选中链条最末端的节点。也可以点「运行全部」（图库工具栏的下拉框）让它对图库里每张图都跑一遍。

- **左侧项目树**：所有可用的功能方框，分成四组：**采集**（图像从哪来）、**处理**（改图像）、**检测**（找特征）、**识别**（人脸/颜色，**尚未实现**）。

- **画布下方提示条**：显示"未选中节点"或当前选中节点的名字。

## 三、按钮与控件逐个说明

### 3.1 顶部按钮条（从左到右）

| 按钮 | 作用 | 备注 |
|---|---|---|
| **菜单** | 弹出菜单栏 | 菜单栏里只有两项：**设置 → 摄像头设置**（改相机编号）；**方案 → 打开方案… / 保存方案 / 另存为…** |
| **启动** | 打开摄像头并实时预览；预览时按"视频处理方式"顺带跑流程 | 这是**老式**的摄像头按钮。M4 之后**推荐用画布上的「相机源」节点**（见 FAQ 9.7） |
| **停止** | 关掉摄像头预览、停止自动播放、**并结束正在录制的视频** | 相机源节点这条路：这里只停画面，**不关相机**；关相机要靠"删除"（见图库工具栏） |
| **打开文件** | 选一张或多张图片导入图库并显示最后一张 | 支持 png / jpg / jpeg / bmp / tif / tiff |
| **单步执行** | **只执行当前选中的那一个节点** | 输入 = 沿"图像源"绑定追到上游起点的那张图。想存"处理后的图"请用连续执行 |
| **连续执行** | 按流程顺序执行，**执行到当前选中的节点为止** | 执行范围由图库工具栏的下拉框决定（运行全部 / 运行选中） |
| **保存项目** | 把**当前这一页**流程图存成 `.vfproj` 方案文件 | 这一页已经有对应文件就直接覆盖保存；没有会弹"另存为" |
| **导入项目** | 打开一个 `.vfproj`，**追加**成一页新流程图 | 已有的页面不会被覆盖 |

> **"保存项目 / 导入项目"和菜单里的"保存方案 / 打开方案"是同一件事的两套入口。**

### 3.2 图库工具栏（显示区下方，从左到右）

| 控件 | 作用 | 备注 |
|---|---|---|
| `图像源 (n/N)` | 图库里有多少张图、当前是第几张 | 只是计数显示 |
| `□ 自动切换` | 勾上后：执行/播放时会**自动切到下一张**（批量跑图时用） | 视频源/相机源勾上它 + 点执行 = **按原帧率自动播放** |
| `[运行全部 ▾]` | **执行范围**：`运行全部` = 连续执行对**图库里每张图**都跑一遍；`运行选中` = 只跑当前选中的那张 | ⚠️ 这个下拉框**只选模式，不执行**；真正执行要点顶部「连续执行」 |
| `停止` | 停止批量执行（急停）+ 停止自动播放 + **收尾正在录制的视频文件** | 录制中一定要点它（或换页/关程序，见 FAQ） |
| `＋图片` | 添加图片到图库 | 可多选 |
| `＋文件夹` | 把一个文件夹里的图片全加进图库（不递归子目录） | 坏文件自动跳过、不弹提示 |
| `删除` | 删除图库里选中的条目 | 会同时清掉相关节点里的路径、该图的参数存档与结果缓存；**图库空了会清空画布** |
| `∨ / ∧` | 折叠 / 展开缩略图列表 | 点一下切换 |

### 3.3 画布操作

| 操作 | 效果 |
|---|---|
| 双击左侧树项 | 在画布上**新建**一个该功能的方框 |
| 把树项**拖到**画布上 | 同上，方框落在鼠标松开的位置 |
| 拖动方框 | 移动节点；连线会跟着动 |
| 从**下方圆点（输出端口）**拖到另一个方框的**上方圆点（输入端口）** | 连一条线（松手前有一条虚线预览） |
| **右键点方框** | 弹出菜单：**删除节点**（连在它上面的线会一起删掉） |
| **右键点连线** | 弹出菜单：**删除连线** |
| 鼠标滚轮 | 缩放显示区图像 |
| 拖动方框时平移画面 | 按住空白处拖动 |
| 双击方框 | 打开这个节点的**参数窗口** |
| 单击方框 | 选中它（底部提示条显示它的名字）——**决定"连续执行"跑到哪里为止** |
| 页签 **＋** | 新建一页流程图（一个方案文件里只装一页） |
| 页签上的 **×** | 关闭这一页（如果有未保存改动，会问你要不要保存） |
| 双击页签标题 | 就地改名 |

## 四、怎么画流程图

1. **准备图像**：`打开文件` / `＋图片` / `＋文件夹`，或者放一个**图片源 / 视频源 / 相机源**节点让它自己取图。
2. **建节点**：双击树项（或把树项拖进画布）。
3. **连线**：上一个方框**下方的圆点** → 下一个方框**上方的圆点**。
   - 一个节点可以接多个下游（分叉），下游节点也可以从多个上游里**挑一个**当图像源（见 6.3）。
   - **起点节点（图片源/视频源/相机源）不需要连上游**；**输出图像**通常放在最末端（放中间也行，它会把图像原样传给下游）。
4. **设参数**：双击方框 → 在参数窗口里改 → 点「确定」。
5. **执行**：选中你想"跑到哪里为止"的那个节点 → 点「连续执行」。
6. **看结果**：右侧显示图（带绿线/红圆/黄框）、"当前结果"表格（每个节点一行）、以及写进磁盘的文件。

**数据流的两条规则**（决定了你会看到什么）：

- **处理类**（灰度/取反/滤波/二值化/形态学/边缘提取）**会改图像**，下游看到的是改过的图。
- **检测类**（直线/圆）**不改图像**，只把"结果数据"传下去；屏幕上看到的绿线红圆是**软件画给你看的**，不属于图像本身。
  → 所以想把检测结果存成文件，要在"输出图像"里把**「保存内容」选「带检测叠加」**（**默认就是它**）。

## 五、怎么运行：单步执行 / 连续执行 / 执行范围

### 5.1 两种执行方式的区别（最常问的一条）

| | **单步执行** | **连续执行** |
|---|---|---|
| 执行哪些节点 | **只执行当前选中的那一个节点** | 按流程顺序从起点执行，**执行到当前选中的节点为止** |
| 节点的输入 | 沿"图像源"绑定**追到上游起点**的那张图（原图或起点节点给的图），**不跑上游** | 上游已经跑过了，拿到的是**上游处理后的结果** |
| 什么时候用 | 调一个节点的参数、想马上看这个节点的效果 | 跑整条流程、看到最终结果、把结果写文件 |
| 日志 | 一行（只有这个节点） | 每个执行到的节点一行 |
| 选中"输出图像"时 | 存的是**起点原图**（因为这一轮只跑了它自己） | 存的是**整条链处理后的结果** |

> 一句话：**要存"处理过、带检测"的结果，就用「连续执行」并且选中链条末端的节点（通常是「输出图像」）。**

**为什么"连续执行"要"执行到选中节点为止"？** 这是为了跟画面一致：**画面上你点哪个节点，就显示"执行到那个节点为止"的结果**。
执行范围也跟着画面走 —— 选中前面的节点时，后面的节点（包括「输出图像」）**不会**执行，所以不会偷偷给你存文件。
（如果你希望"选中任一节点都把整条链跑完"，那是另一种语义，可以提出来改。）

**孤立节点**（没连任何线的方框，起点类除外）不会被执行，日志里会提示"以下节点本次未执行"。

### 5.2 执行范围（图库工具栏的下拉框）

- **运行全部**：点「连续执行」时，对**图库里的每一张图**都跑一遍（日志逐张累积；某张出错会跳过继续跑）。
- **运行选中**：只跑图库当前选中的那一张。
- 图库为空时：如果有**图片源 / 视频源 / 相机源**节点给图，照样能跑；都没有会提示"请先导入图片/视频"。

### 5.3 停止 / 自动播放

- **停止**（图库工具栏）：急停批量执行；停自动播放；**并收尾正在录制的视频文件**（很重要，见 FAQ 9.9）。
- **自动切换**（勾选框）+ 点执行：
  - 对**视频源** = 按视频原帧率**自动一帧帧播**（到末尾按"到末尾回到开头"决定循环还是停）。
  - 对**相机源** = 相机画面**持续刷新**，一直到你点「停止」（相机会保持打开，只是停止刷画面）。

## 六、参数窗口详解

双击任意方框打开参数窗口。窗口里最多有**三个页签**和**三个按钮**。

### 6.1 三个页签

| 页签 | 里面是什么 | 哪些节点有 |
|---|---|---|
| **基本参数** | **图像源绑定**（这个节点从哪张图开始算）+ **ROI（处理区域）** 的一切设置 | 处理类 / 检测类有；**起点节点、输出图像没有这一页**（它们没有上游，也不需要用 ROI） |
| **运行参数** | 这个节点自己的算法参数 | 除**灰度**以外的节点都有（灰度的 Canny/Hough 参数没有意义，所以整页隐藏） |
| **显示结果** | 结果显示 + "直线数量 / 圆数量"这类计数 | 处理类、起点节点、输出图像**没有**（它们没有结构化结果）；直线 / 圆 / 灰度里有（灰度只保留"基本参数"页） |

### 6.2 三个按钮（**这是最容易用错的三个按钮**）

| 按钮 | 它做什么 | 什么时候用 |
|---|---|---|
| **执行** | 等价于主界面的**「单步执行」**：只跑**当前这个节点**，输入是追到上游起点的那张图 | 调本节点参数，想立刻看"这个节点单独作用"的效果 |
| **连续执行** | 等价于主界面的**「连续执行」并选中本节点**：从流程起点一直跑到**本节点**为止 | 调完参数想立刻看"整条链到这儿"的效果（也才会让上游的改动生效） |
| **确定** | **保存参数并关闭窗口**。对**起点节点**（图片源/视频源/相机源）就是"只存参数、不执行"；对其它节点会**先执行一次单步**再关（这样你能马上看到效果） | 参数改完收工 |

> 另外两个小按钮在"基本参数"页里：**框选**（在显示图上拉框画 ROI）、**ROI参数**（展开/收起 ROI 的数字输入）。
>
> ⚠️ **起点节点**（图片源 / 视频源 / 相机源）的窗口里**没有「执行 / 连续执行」两个按钮** —— 它没有上游，单独"执行它"没有意义，所以只留「确定」（点它只保存参数）。

### 6.3 基本参数页：图像源绑定 + ROI

**图像源绑定**（决定"这个节点的输入图像从哪来"）：

| 选项 | 含义 |
|---|---|
| **自动** | 默认。引擎自动挑：单个上游就用它；多个上游时，优先挑"**会改图像**的那些上游里最靠后的一个" |
| 指定某个上游节点 | 明说"我从这个节点拿图"（分叉流程里很有用） |
| 全局图像源 | 用主窗口当前显示的那张图（等于"不接上游"） |

**ROI（处理区域）**：

| 项 | 作用 |
|---|---|
| **X / Y / W / H** | 处理区域的左上角与宽高（像素）。算法**只在这块区域里算** |
| **框选** | 用鼠标在当前显示图上拉一个框，自动填进 X/Y/W/H |
| **形状** | `矩形` 或 `圆`（圆 = 以该框的中心与半径画圆，显示上就是一个圆圈） |
| **屏蔽形状** | 勾上后屏幕**不画**这个 ROI 框（算法照旧只用这块区域） |
| **外扩** | 继承来的 ROI 往外扩多少像素（见下） |
| **继承自** | `上游ROI框` = 沿用上游节点实际用的那块区域；`上游结果框` = 用上游**检测结果的外接框**（例如"圆"检出的那个圆的外接框） |
| （勾选）**继承上游** | 勾上 = 本节点**不自己画框**，用上游的框（配合"继承自"和"外扩"）。勾上后 ROI 数字区会置灰 |
| **位置修正**（直线/圆窗口里的 5 个框） | 那是**算法参数**（Canny / Hough 那几项），不是 ROI —— 见第七节 |

> **ROI 继承的典型用法**：`图片源 → 圆（找到圆）→ 二值化（勾"继承上游"、继承自"上游结果框"、外扩 5）`
> 这样二值化**只处理检出来的那个圆内部**，而不是整张图。
> 日志里会写清楚继承有没有生效：`← 继承上游ROI框` / `← 继承上游结果框` / `← 继承未生效（改用本节点 ROI）`。

## 七、每个节点模块的参数作用

**控件类型说明**：`下拉框` = 从几个选项里选一个；`整数/小数` = 数字输入框；`勾选框`；`文件/文件夹` = 右边有"浏览…/选择目录…"按钮；
`文本` = 纯文字输入。**"默认"列是新建节点时的取值。**

### 7.1 采集组

#### 图片源（流程起点）

| 参数 | 控件 | 默认 | 作用 |
|---|---|---|---|
| 图像来源 | 下拉框 | 图片 | `图片`（用下面那个路径）/ `文件夹`（取文件夹里按名字排序的第一张）/ `测试图`（软件自带的一张测试图） |
| 路径 | 文件 | 空 | "图像来源 = 图片"时读哪张图 |

> 图片源节点**没有"基本参数"页**（没有上游），窗口里只有"运行参数"和"确定"。

#### 视频源（流程起点）

| 参数 | 控件 | 默认 | 作用 |
|---|---|---|---|
| 视频路径 | 文件 | 空 | 要读的视频（mp4 / avi / mkv / mov） |
| 当前帧号 | 整数 | 0 | 这一轮读第几帧。**每执行一次自动 +1**（见"执行后前进一帧"） |
| 执行后前进一帧 | 勾选框 | ✅ | 取消勾选就"卡"在这一帧不动（调参时很有用） |
| 到末尾回到开头 | 勾选框 | ⬜ | 播到最后一帧后是循环还是停下 |

> 勾上工具栏的**"自动切换"**再点执行 = 按**原帧率自动播放**；点「停止」停播。
> 视频的参数是**"整段共用"**的（换视频才重新载入），不会像图片那样一张一份。

#### 相机源（流程起点）

| 参数 | 控件 | 默认 | 作用 |
|---|---|---|---|
| 相机类型 | 下拉框 | USB 相机 | **V1 只支持"USB 相机"**；"网络相机（预留）""工业相机（预留）"是**灰的、点不了** |
| 相机编号 | 整数 | 0 | 第几号摄像头（0 = 通常是第一个；编号也可在 菜单→设置→摄像头设置 里改） |
| 分辨率 | 下拉框 | 默认 | ⚠️ **当前版本"只存不生效"**：实际分辨率由摄像头自己给（预留下的参数） |
| 执行时自动打开相机 | 勾选框 | ✅ | 勾上则执行时若相机没开就自动打开（省得先去点「启动」） |

> **相机源节点直接复用主窗口的相机**，所以它和「启动」按钮**共用同一个设备、不会抢**。
> 相机画面**不进结果缓存**（每帧都不同，缓存没意义）。
> **「停止」= 暂停**（画面停住、保留最后一帧、相机不关）；**要关相机**：删掉图库里的相机条目 / 关闭程序。

#### 输出图像（输出节点）

| 参数 | 控件 | 默认 | 作用 |
|---|---|---|---|
| 输出目录 | 文件夹 | **空** | **必须自己选一次**（本项目特意不设默认目录，避免"默默写到某个地方"）。留空时执行**只写日志、不保存、不弹窗** |
| 输出文件名 | 文本 | 空 | 不含扩展名。**留空 = 用输入图片的文件名**（"运行全部"时每张图各用各的名字） |
| 输出类型 | 下拉框 | **自动** | `自动` = 跟输入走（图片源 ⇒ 存图片；视频源/相机源 ⇒ **存视频文件**）；也可手动选 `图片序列` / `视频文件` |
| 图片格式 | 下拉框 | PNG（无损） | 只在"图片序列"模式用：PNG / JPG / BMP / TIFF |
| 视频格式 | 下拉框 | MP4（mp4v） | 只在"视频文件"模式用：**MP4·mp4v**（体积小，约 7.7 MB/分钟@720p）/ AVI·XVID / AVI·MJPG（最兼容、约 23 MB/分钟） |
| 视频帧率 | 小数 | 0 | 0 = **跟来源**（视频源读到的帧率 / 相机按 30）；也可手填（例如 10） |
| **保存内容** | 下拉框 | **带检测叠加** | `数据层图像` = 纯处理结果（灰度/二值化的结果，**不含**绿线红圆）；`带检测叠加` = 处理结果 **+ 检测到的绿线/红圆**（不画 ROI 辅助框） |
| 重名策略 | 下拉框 | 自动编号 | `自动编号`（`名字_0001.png`，重开软件也不覆盖）/ `覆盖同名` / `按时间戳` |

> **放中间也可以**：输出节点把图像**原样传给下游**，插在流程中间不影响后面的结果。
> **参数是"流程级"的**：换图片不会清空输出目录/文件名（这是故意的）。
> **录制**：视频/相机输入时，**第一次执行到它**就开始录，之后每执行一帧写一帧；**点「停止」结束录制**（换页、删节点、关程序、关相机也会自动结束）。

### 7.2 处理组（都会改变图像，下游看得见）

| 节点 | 参数 | 控件 | 默认 | 作用 |
|---|---|---|---|---|
| **灰度** | 作用于整图 | 勾选框 | ⬜ | 勾上 = **忽略 ROI**，整幅图转灰度；不勾 = 只把 ROI 那块转灰度 |
| **取反** | —— | | | 没有参数：255 - 像素值（只在 ROI 内） |
| **滤波** | 滤波方式 | 下拉框 | 高斯 | 均值 / 高斯 / 中值 |
| | 核大小 | 整数（奇数） | 3 | 1~31，自动取奇数 |
| | 高斯标准差 | 小数 | 0.0 | 0 = 由核大小自动推 |
| **二值化** | 阈值方式 | 下拉框 | 固定阈值 | 固定阈值 / Otsu（自动阈值）/ 自适应 |
| | 阈值 | 整数 | 127 | 固定阈值时用 |
| | 最大值 | 整数 | 255 | 超过阈值的像素设成多少 |
| | 类型 | 下拉框 | 二值 | 二值 / 反二值 |
| **形态学** | 运算 | 下拉框 | 腐蚀 | 腐蚀 / 膨胀 / 开运算 / 闭运算 / 梯度 / 顶帽 / 黑帽 |
| | 核形状 | 下拉框 | 矩形 | 矩形 / 椭圆 / 十字 |
| | 核大小 | 整数（奇数） | 3 | 1~31 |
| | 迭代次数 | 整数 | 1 | 1~10 |
| **边缘提取** | 方法 | 下拉框 | Canny | Canny / Sobel / Laplacian |
| | 低阈值 / 高阈值 | 整数 | 50 / 150 | Canny 用 |
| | 核大小 | 整数（奇数） | 3 | Sobel / Laplacian 用 |

### 7.3 检测组（**不改图像**，只出结果）

#### 直线（窗口里的 5 个数字来自"位置修正"那一组，其实是算法参数）

| 参数 | 默认 | 作用 |
|---|---|---|
| Canny 低阈值 | 50 | 边缘检测的低阈值（越高，能算作"边缘"的门槛越高） |
| Canny 高阈值 | 150 | 边缘检测的高阈值 |
| 累加器阈值 | 100 | Hough 投票门限：**调小 = 检出更多（也更容易误检）** |
| 最小线段长度 | 100 | 短于此长度的线段丢掉 |
| 最大线段间隙 | 10 | 同一条线上允许断开多大 |
| （显示结果页）直线数量 | — | 本次检出的条数 |

#### 圆（同样那 5 个框，含义不同）

| 参数 | 默认 | 作用 |
|---|---|---|
| 累加器分辨率(dp) | 1.00 | 累加器分辨率与图像分辨率的反比（1 = 相同） |
| 圆心最小距离(minDist) | 150 | 两个圆心至少隔多远，避免重复检同一个圆 |
| Canny高阈值(param1) | 100 | 边缘检测高阈值（低阈值取它的一半） |
| 累加器阈值(param2) | 80 | **调小 = 检出更多圆（也更容易误检）** |
| 最小半径(minRadius) | 20 | 小于此半径的圆不算 |
| （算法内部）最大半径 | 0 | 目前**界面上没有这个控件**，恒为 0 = 不限制 |

> **实测小贴士**：上面这张"测试图"里那个半径 80 的圆，用默认 `param2 = 80` **检不出来**，把它调到 **30** 就能检到 1 个。

| 数据 | 存在哪 | 说明 |
|---|---|---|
| **图像/视频文件** | 你自己选的位置 | 「打开文件」「＋图片」「＋文件夹」导入的都是"引用"，软件不会复制它们 |

| **开发日志** | 工程目录 `pyside6.txt`（另有 `plan/pyside6_开发日志.md`） | 每个改动一条记录 |

## 九、常见问题 FAQ

### 9.1 点「连续执行」弹提示"请先导入图片/视频"，但我不想导图
说明**画面里没有任何可用的图**。两种解法：① 用「打开文件/＋图片」导一张；② 在流程里加一个**起点节点**（图片源 / 视频源 / 相机源）并设好路径/编号——起点节点能自己给图，不依赖图库。

### 9.2 我选中了前面的节点执行，为什么后面的「输出图像」没存文件？
这是**故意的**：**「连续执行」只执行到当前选中的节点为止**，跟画面上"点谁看谁"保持一致。
要存文件就**选中「输出图像」（或它后面的节点）**再执行；想整条链都跑，选中链条末端的节点即可。

### 9.3 存出来的图上没有绿线/红圆
因为"直线/圆"**不改图像**（它们只产出结果数据）。检查「输出图像」的 **保存内容** 是不是被改成 `数据层图像` 了 —— 选 **`带检测叠加`**（默认）就会把检测结果画上去。
> 注意：叠加只画**检测结果**，不画 ROI 辅助框。

### 9.4 单步执行选中「输出图像」，存下来的为什么是原图？
因为**单步执行只跑这一个节点**：没有跑上游，也就没有"处理后的图"可存，它拿到的只能是追到起点的那张原图。
→ 要保存处理结果，请用**「连续执行」**并选中输出节点。

### 9.5 输出目录为什么每次都要自己选？
这是刻意的设计：**不设默认目录**，避免软件在你没注意的时候往某个地方写文件。
留空时执行**只会在日志里写"未保存/未录制：没有设置输出目录"**，不会弹窗、不会偷偷存。

### 9.6 相机打不开 / 日志写"没有可用的相机画面（相机未打开？编号 N）"
按顺序排查：
1. 相机编号对不对（画布上的相机源节点参数 / 菜单→设置→摄像头设置）；
2. 相机是不是被**别的程序**占用了（微信、相机应用、浏览器视频等要先退出）；
3. 相机源节点的 **「执行时自动打开相机」** 是否被取消勾选了（取消后就要手动点顶部「启动」）；
4. 「停止」只是暂停画面、**不关相机**；如果你把图库里的相机条目删了，相机就关了，需要重新打开。

### 9.7 顶部「启动 / 停止」和画布上的「相机源」节点有什么区别？
- 顶部那对按钮是**老式**的摄像头预览（点开就一直刷新画面）；
- **相机源节点**是把它当成数据流的起点（可以接处理/检测/输出，参数与其它算子一致）；
- 两者**共用同一个相机设备**（不会抢），可以混用。顶部那对按钮**以后可能会被移除**，新流程建议直接用相机源节点。

### 9.8 视频源只出了一帧就不动
- 想让每次执行前进一帧：勾上 **「执行后前进一帧」**；
- 想让它像播放器一样自己跑：勾上工具栏的 **「自动切换」**，然后点「执行/连续执行」；点「停止」停播；
- 到末尾就不动了：那是没勾 **「到末尾回到开头」**（循环）。

### 9.9 录制到一半想停 / 录制中文件为什么打不开
- **结束录制**：点图库工具栏的 **「停止」**；另外**换页、删掉输出节点、关闭程序、关闭相机**也都会自动结束录制；
- **录制中的文件还打不开**是正常的：视频文件要等编码器**收尾（release）**才写完头部信息。所以别在录制中直接拷走它。

### 9.10 参数怎么"按图片分别记"？为什么我换了图参数就变了？
这是本软件的核心特性之一：**同一个流程图可以套用到图库里的每一张图，每张图各自记一套参数**（ROI、阈值…）。
换图时参数自动切换。**起点节点和输出节点的参数是流程级的**（所有图片共用），因为它们描述的是"数据从哪来、往哪去"，不该按图变。

### 9.11 双击「人脸」「颜色」没反应
这两个模块**尚未实现**（树里保留位置）。放进流程里执行时，日志写"模块未实现"，图像会原样传给下游。

### 9.12 方案文件（.vfproj）里有什么？为什么我保存了两页只有一个文件？
方案文件是 JSON，里面是**一页**流程图的节点、坐标、连线、参数与"按图参数"。
**一个文件只装一页**：所以两页要保存两次（"保存项目"保存的是**当前这一页**）。用"导入项目"打开一个方案时，它会**追加**成一页新页，不会覆盖你现在的工作。

### 9.13 视频文件很大
720p 下实测：**MP4·mp4v ≈ 7.7 MB/分钟**、AVI·XVID ≈ 7.9、AVI·MJPG ≈ **23 MB/分钟**（MJPG 最兼容但最大）。
想省空间就选默认的 **MP4·mp4v**；想"任何播放器都能打开"就选 AVI·MJPG。

### 9.14 有撤销（Ctrl+Z）或快捷键吗？
**暂时没有**。（键盘快捷键也还没做。）改动前建议用"保存项目"留一份方案文件。

### 9.15 我把图库里的某张图删了，为什么流程里的节点路径也空了？
这是有意的防错设计：删除图库条目会**同时清掉引用它的节点路径**，避免流程里留着一个"指向已删除文件"的假参数。顺带也会清掉这张图的参数存档、结果缓存与缩放记录。

## 十、已知限制

| 限制 | 说明 |
|---|---|
| 识别类（人脸、颜色）未实现 | 树里占位；流程里执行会写"模块未实现" |
| 相机"分辨率"只存不生效 | V1 预留下的参数，实际分辨率由相机决定 |
| 相机类型只有 USB 可用 | 网络相机 / 工业相机预留并置灰 |
| 相机帧不进结果缓存 | 每帧都不同，缓存无意义 |
| 视频录制的帧率是"标称值" | 按"每写一帧算一帧"，不按墙上时间推算真实帧率 |
| 没有撤销/重做、没有快捷键 | —— |
| 执行是在界面线程里同步跑的 | 大批量跑图时界面会"卡"到跑完（点「停止」可以急停） |
| 结果缓存没有容量上限 | 长时间大量跑图会占内存（换图/关页会释放相应部分） |
| 视频文件"分段"靠尺寸/参数变化触发 | 录制中没有"最长时长/最大体积"上限 |
| 一页流程图 = 一个方案文件 | 多页要分别保存 |
