## 二、算子级附表（14 个算子，各一行）

| 算子 | 拖出来点一下「执行」应看到 | 备注 |
|---|---|---|
| 图片源 | 按"来源"给出图像（单张图 / 文件夹 / 当前图像 / 测试图） | 起点节点：窗口只有"运行参数"页 + 只留「确定」；不画 ROI 框 |
| 视频源 | 一次执行 = 前进一帧；勾"自动切换"按原帧率播放 | 参数"整段共用一份" |
| 相机源 | 出相机画面（复用主窗口相机） | 停止 = 暂停；删除节点才关设备 |
| 输出图像 | 按参数把图/视频存到磁盘，日志写"已保存 …" | 「保存内容」默认"带检测叠加"；中文路径可用 |
| 灰度 | ROI 内变灰（3 通道灰度） | 有"作用于整图"开关（专用窗口） |
| 取反 | ROI 内反色 | 没有可调参数（运行参数页给一行灰字提示） |
| 滤波 | 均值 / 高斯 / 中值，核大小必须是奇数 | 偶数会被纠正成奇数 + 提示 |
| 二值化 | 固定阈值 / Otsu / 自适应 | 阈值 0~255，越界会被夹回 |
| 形态学 | 腐蚀/膨胀/开/闭/梯度/顶帽/黑帽 + 核形状 + 迭代 | 7 档共用一个节点（参数同构） |
| 边缘提取 | Canny / Sobel / Laplacian | 低>高会被互换 + 提示 |
| 直线 | 检出绿线（显示层），日志"检测到 N 条直线" | 检测类不改图；可被下游"继承结果框" |
| 圆 | 检出红圆 + 圆心 | `param1/param2` 下限是 1（0 会崩，已修） |
| 人脸识别 | 检出人脸绿框，日志"检测到 N 张人脸" | 级联文件不设默认值；**换图不重置**；出错红字 |
| 颜色提取 | 阈值内保留原色、阈值外置黑 | HSV / RGB 两套阈值；只在 ROI 内提取 |

> 算子级附表对应的自动用例：`dsh_m2_check.py`（处理类 + 检测类 + 树）、`dsh_morph_gray_check.py`（灰度 / 形态学）、
> `dsh_p4_rules_check.py`（各算子的参数规则表）、`dsh_m2_face_check.py` / `dsh_m2_color_check.py`（识别类）。

## 三、已知"范围外 / 暂不做"（**别当 bug**）

1. **每 N 帧检测一次**（视频源）：用户 2026.10.7 决定暂不做（《批次4 技术方案》《九、想法》9.2 留了实现要点）；
2. **参数联动置灰**（选 Otsu 灰掉"阈值"）：地基（`visible_when`）已就绪，只差给那两行加一条声明（§6.5 / 9.8 第 2 条）；
3. **圆"最大半径"控件**：没补 ⇒ `min_radius <= max_radius` 那条规则不可达（§6.5 / 9.8 第 3 条）；
4. **输出目录不存在时自动建 / 提示**：现在只写日志（其实保存时会自动建目录，见 §6B.9；"未设置输出目录"时只记日志）；
5. **提示行实时刷新**：现在只在点「执行 / 连续执行 / 确定」时算一次（9.8 第 5 条）；
6. **提示行"自动滚到可见"**：装不下的窗口里提示可能在折叠线以下（9.8 第 6 条）；
7. **颜色提取的增强**：多段阈值（红色在 HSV 跨 0/179）、其它颜色模型（Lab / 灰度带）、阈值命中预览（9.11）；
8. **"模块未实现""参数非法已跳过"也标红**：错误通道已就绪，加一个 `__error__` 即可（9.11 第 4 条）；
9. **节点错误态图标**（VM 式：节点左边绿图标、出错变红）：**批次5 之后**再做（9.10）；
10. **批次5 重构**：目录重构（一节点一文件 → 按大标题分文件夹，9.9）、拆 `MainWindow`、执行线程化、
    结果缓存上限、撤销 / 重做。

> **注**：上表"历史用例"指 `dsh_single_page_check.py` / `dsh_toolbar_check.py` 这两套**早期留档用例**
> （门禁已经不再收集它们：它们引用的是被改过的老控件），验收时以现行界面与实际行为为准。
