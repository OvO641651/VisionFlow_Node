## 二、总目标与验收方式

### 2.1 总目标

把界面从"能用"改成"**像 VM 类软件那样好用、好看**"：**画布（节点 + 网格 + 小地图 + 对齐 + 右键建节点 + 滚动条修好）· 树（搜索）· 日志 + 结果详情 + 帮助页 + 可拖分界线 · 图片信息条 · 图标**。
**不改算法、不改数据流语义** —— 本批次只动"长什么样 / 怎么操作"。

### 2.2 编号原则（★ 用户原话入档）

> "**我打算按照ui的区域来分目标，如果该目标的任务较多，那么就添加M批次**。"（用户 2026.10.16）

⇒ **批次6 = 目标1~目标5，按 UI 区域划分**（画布 / 树 / 日志+帮助 / 图片信息条 / 图标）；
**目标内部任务多时再加 M**（日志标题按 `批次6目标1-M2` 这种写法，见规矩 3）。**M 分批表见 §3.2**。

### 2.3 ★ 验收方式（用户已点选：甲）

**甲 = 改前 / 改后截图对照 + 新基线登记 + 功能用例一套不少**，落地办法：

1. **每个 M 动手前**先截"改前"图（`backups\_ui_preview\`），改完截"改后"图，**两张都记 sha256**，并**登记《截图索引》**；
2. **功能用例一套不少**：门禁 **44 套 1018 项**必须全绿（UI 改动最容易碰到 `dsh_m2_v5_check` / `dsh_width_check` / `dsh_t5g2_api_check` / `dsh_doc_consistency_check`）；
3. **行为不回归**：只准改"外观"，结果类断言（逐像素一致、缓存键、撤销语义…）继续有效；
4. **用户手工验收**：每个目标做完请用户看一眼（批次5 的老做法 = "用户点选 → 我落地 → 用户复测"）。

> ★ **批次6 的"改前基线"已经钉好**（2026.10.16）：`t6_baseline_mainwindow.png`（主界面全貌）·

> 工具 = `temp\dsh_t6_shot_baseline.py`（改后用同一支脚本抓，逐像素对照）。

### 2.4 ★ UI 改动的三条硬约束（批次5 实测踩过，写在这里防回归）

1. **控件对象名尽量不动**：44 套门禁里**大量直读**运行时控件名，例如
   `w.btn_continuous` · `w.execution_log` · `w.gallery_widget` · `w.image_view` · `w.action_undo` · `w.btn_undo` …
   ⇒ **只改外观与布局最省事**；确实要改名的（例如**删掉「启动」「停止」两个按钮**），必须**先 grep 用例引用、同批同步改用例**，并在日志里写清改了哪些。
2. **`.ui` 只是"摆占位"，真源在运行时**：控件由 `QUiLoader` 载入 + `main.py` 里 `findChild` 收编
   ⇒ 删 / 挪 / 改名控件会让 `findChild` 返回 `None`（有兜底的地方会静默自建，反而更难发现）⇒ 改 `.ui` 后**要逐条核对 `findChild` 的调用点**。
3. **批次5 的"界面零变化"红线在批次6 作废**，换成 §2.3 的"**截图对照 + 新基线 + 用例全绿**"。

## 七、批次6 目标4：图片信息条 + 结果详情页

### 7.1 M1 图片右下角透明信息条（**用户拍板 F：1 移出隐藏、2 不显示缩放比**）

- **用户原话**："在**图片右下角添加一个透明的横条**，用于存放**当前鼠标在图片上的位置**，及该图片的 **BGR 数值**，图片的**尺寸**等数据"；
  **格式参考**：`3840 * 2748 | X:2322 Y:2727 | R:153 G:153 B:153`。
- **做法**：
  1. 在图片视图（`widgets/ImageGraphicsView.py`）**自绘**一条半透明横条（右下角，圆角 + 深色底 + 浅色字）——自绘省控件、不动 `.ui`；
  2. `mouseMoveEvent` ⇒ **视图坐标换算回原图坐标**（`mapToScene` + 缩放比 + 图像原点，**这里最容易错**）⇒ 取该像素 **BGR**（**OpenCV 是 BGR，界面按 `R:G:B` 显示 ⇒ 要换顺序**）；
  3. 尺寸显示原图 `宽 * 高`；**鼠标离开图片区 ⇒ 不显示**（用户拍板 F-1）；**不显示缩放比例**（F-2）；
  4. **性能**：`mouseMoveEvent` 只做取值 + `update()`，**不要每移动一像素重建 QPixmap**。
- **判据**：① 鼠标放到已知像素上 ⇒ 显示的 `X/Y` 与 `BGR` 与脚本直读的像素值**逐值一致**；② **缩放后**仍一致（断言"缩放 2 倍后同一图像坐标的数值不变"）；③ 移出图片区 ⇒ **不显示**；④ 图片为空时信息条不画。
- **落点**：`widgets/ImageGraphicsView.py`（鼠标事件 + 叠加绘制）· `main.py`（把"当前图"给视图）。
